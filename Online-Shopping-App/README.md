# VIVA — Online Shopping App

React + Vite implementation of Assignment 5: Online Shopping Cart.

## Assignment requirements
- Product list
- Add to cart
- Remove item
- Quantity update
- Grand total
- Percentage coupon discount
- GST calculation
- `useReducer()` for cart/state transitions
- Context API for shared application state

## Included production-style features
- Responsive marketplace UI for desktop, tablet, Android and iPhone sizes
- Green VIVA visual system with light/dark mode
- 115 products across electronics, fashion, ethnic wear, shoes, home, beauty, sports, books, grocery and health care
- Popular-brand filtering and dedicated brand pages
- Search suggestions and dedicated search-result page
- Catalog filters: category, brand, rating, maximum price, 50%+ deals
- Sorting: featured, discount, price and rating
- 50%+ Deals page and working flash-deal countdown
- Wishlist and persistent cart
- Quantity stepper changes product cards to `Added to Cart`
- Buy Now adds the selected product to the cart before opening the cart
- Editable checkout address
- Persistent order history
- Detailed Track Order cards with clickable products
- Order cancellation with reason selection
- Accessible reduced-motion support
- Vercel SPA rewrite configuration

## Run locally
```powershell
npm install
npm run dev
```

Build for production:
```powershell
npm run build
```

No API keys, environment variables, backend or database setup is required.
