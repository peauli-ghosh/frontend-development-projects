# Front-End Development Projects

A growing collection of web development projects built to explore modern frontend development, user interfaces, application architecture, API integration, state management, authentication, and responsive design.

This repository contains individual projects developed with different concepts, technologies, and implementation approaches. Each project is maintained in its own directory with its own source code, documentation, and configuration.

## Projects

### Portfolio
A responsive personal portfolio website built with React and Vite, featuring sections for introduction, education, skills, projects, and contact information.

**Tech:** React, Vite, JSX, CSS

### Student Information Management
A student information management interface designed to organize and display student-related information through a responsive web application.

**Tech:** React, JavaScript, CSS

### Employee Directory
An employee management application supporting employee creation, editing, deletion, searching, and temporary JSON-based data persistence.

**Tech:** React, JavaScript, JSON Server, CSS

### Weather Dashboard
A weather application that integrates external weather APIs to provide current weather information, search functionality, weather-based visuals, air quality information, and responsive layouts.

**Tech:** React, Vite, REST API, JavaScript, CSS

### Online Shopping App
A responsive e-commerce application featuring product browsing, search, categories, cart management, wishlist functionality, coupons, GST calculation, checkout flow, delivery information, and order history.

**Tech:** React, Context API, useReducer, JavaScript, CSS

### Task Manager
A task management application focused on organizing tasks through routing, task creation, editing, completion tracking, and application-level state management.

**Tech:** React, React Router, JavaScript, CSS

### Authentication System
A full-stack authentication application implementing real user registration, login, logout, protected routes, password hashing, JWT-based sessions, password strength validation, and persistent user authentication.

**Tech:** React, Vite, Node.js, Express, SQLite, JWT, bcrypt

## Running a Project

Each project contains its own setup and dependencies.

Navigate into the project directory and install its dependencies:

```bash
npm install
```

Then start the development server:

```bash
npm run dev
```

For full-stack projects, the frontend and backend may need to be started separately. Refer to the individual project's README for project-specific instructions.

## Deployment

Selected projects in this repository are deployed using platforms such as Vercel and Render.

Deployment configuration is maintained within the respective project directories.
