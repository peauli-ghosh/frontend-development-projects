# Peauli — Developer Portfolio

A personal developer portfolio website built to showcase my education, technical skills, projects, and development experience.

The portfolio uses a clean, modern developer-focused design with a dark theme, purple accent color, and light mode.

## Features

- Responsive portfolio website
- Dark mode and light mode
- Hero section with personal introduction
- About section
- Education timeline
- Technical skills
- Selected projects
- Contact section
- Responsive navigation
- Smooth scrolling
- Mobile-friendly design

## Tech Stack

- React
- Vite
- JavaScript
- HTML5
- CSS3

### Development Technologies

- Python
- FastAPI
- MySQL
- SQLAlchemy
- REST APIs
- Git
